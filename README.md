# UnoCSS Preset Vinicunca

UnoCSS preset for Vinicunca projects: wind4 with fluid sizing, enter/exit animations, scrollbar, and Magic CSS presets.

Read the [documentation](https://vinicunca.dev/unocss-preset/).

The docs live in [vinicunca/docs](https://github.com/vinicunca/docs). After each release, the `notify-docs` job asks that repo to open a PR that bumps its pinned version of this package.
