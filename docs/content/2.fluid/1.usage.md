## Setup

Enable the fluid preset through `presetVinicunca`. Its default classes use the `fluid-` prefix, pixel values, and a viewport range from 320px to 1920px.

```ts [uno.config.ts]
import { presetVinicunca } from '@vinicunca/unocss-preset';
import { defineConfig } from 'unocss';

export default defineConfig({
  presets: [presetVinicunca()],
});
```

Set both endpoints with a slash, or use the three explicit classes:

```html
<div class="fluid-w-100/200">...</div>
<div class="fluid-w fluid-w-min-100 fluid-w-max-200">...</div>
```

The value is 100px at or below 320px viewport width, grows smoothly between 320px and 1920px, and is 200px at or above 1920px.

## Options

Pass options under `fluid` when you need to change the defaults:

```ts [uno.config.ts]
import { presetVinicunca } from '@vinicunca/unocss-preset';
import { defineConfig } from 'unocss';

export default defineConfig({
  presets: [
    presetVinicunca({
      fluid: {
        minContainerWidth: 320,
        maxContainerWidth: 1920,
        defaultBaseUnit: 'px',
        prefix: 'fluid-',
        expandCSSVariables: false,
        disableTheme: false,
        themeShortcuts: true,
        attributify: false,
        commentHelpers: false,
        utilities: [],
      },
    }),
  ],
});
```

| Option | Purpose |
| --- | --- |
| `minContainerWidth`, `maxContainerWidth` | Viewport widths where scaling starts and stops, in pixels. |
| `defaultBaseUnit` | Unit used for sizes; defaults to `px`. Supported keys are `px`, `rem`, `em`, `vw`, `vh`, `vmin`, `vmax`, `fr`, and `percent`. |
| `prefix` | Prefix for generated utilities and custom properties. |
| `expandCSSVariables` | Emit intermediate custom properties for the fluid calculation. |
| `disableTheme` | Disable the built-in named size shortcuts. |
| `themeShortcuts` | Disable named shortcuts while retaining the underlying fluid utilities when set to `false`. |
| `attributify` | Add attribute-form shortcuts. |
| `commentHelpers` | Reserved option; the current preset does not emit CSS comments. |
| `utilities` | Add or replace utilities as `[name, CSS properties]` pairs. |

For example, `defaultBaseUnit: 'rem'` makes `fluid-w-1/2` scale from 1rem to 2rem. The class `fluid-w-base-rem` can change the base unit for a single utility.

The built-in theme includes shortcuts such as `fluid-p-lg` (32px to 48px) and `fluid-text-lg` (16px to 18px). Set `themeShortcuts: false` to use only numeric classes.

To support another CSS property, add a utility:

```ts
presetVinicunca({
  fluid: {
    utilities: [['stroke', ['stroke-width']]],
  },
})
```

Then `fluid-stroke-1/3` scales `stroke-width` from 1px to 3px.
