## Gap

```html
<div class="grid grid-cols-3 fluid-gap-32/64">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>
```

:docs-fluid-gap

## Margin

```html
<div class="fluid-m-20/40">Margin from 20px to 40px.</div>
```

:docs-fluid-margin

## Padding

```html
<div class="fluid-p-32/64">Padding from 32px to 64px.</div>
```

:docs-fluid-padding

## Theme shortcuts

The built-in `lg` spacing shortcut maps to 32px at the minimum viewport width and 48px at the maximum.

```html
<div class="fluid-p-lg">Padding from 32px to 48px.</div>
```

:docs-fluid-ranges

## Typography

```html
<p class="fluid-text-32/64">
  Font size from 32px to 64px.
</p>
```

:docs-fluid-typography

## Width and height

```html
<div class="fluid-w-100/200 fluid-h-100/200">100px to 200px.</div>
```
